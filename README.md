## Em destaque

### [AppTriagem](https://github.com/gabriellymsb/AppTriagem): triagem de avaliações de clientes com LLM e BERTimbau

Classificador que lê a avaliação de um cliente e identifica o problema principal do pedido (atraso, não recebido, produto errado, entre outras 8 classes).

- Um LLM (Gemini) rotulou os dados de treino; 301 avaliações rotuladas à mão formaram um teste independente
- BERTimbau ajustado com PyTorch e Hugging Face: **92% do F1 do próprio LLM, respondendo em cerca de 3 ms**
- Modelo publicado no Hugging Face e demo que roda direto no navegador (ONNX quantizado + Transformers.js)

[Testar a demo](https://huggingface.co/spaces/gabriellymsb/triagem-avaliacoes) · [Modelo no Hugging Face](https://huggingface.co/gabriellymsb/bertimbau-triagem-avaliacoes) · [Código e análise](https://github.com/gabriellymsb/AppTriagem)
